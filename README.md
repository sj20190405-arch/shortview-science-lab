# 한슬쌤의 '숏'터뷰 통합과학실험실

동패고등학교 1학년 통합과학 가상실험실입니다.
**통합과학2 Ⅰ-2-01 산화·환원 반응의 규칙성** (교과서 38~43쪽, 3/12차시)의 탐구 활동인 **구리와 질산 은 수용액의 산화·환원 반응 관찰하기**를 4단계로 진행합니다.

- 학생: 반·번호·성명을 입력해야 입장할 수 있습니다. 같은 정보로 다시 들어오면 이어서 진행됩니다.
- 교사: 비밀번호를 입력하면 단계별 진행 현황, 학생별 점수, 최종 결과보고서를 볼 수 있습니다.
- 평가 결과(점수)는 교사 화면에만 표시됩니다.

## 평가 구성 (100점, 세부 점수는 1점 단위)

| 단계 | 활동 | 세부 배점 | 합계 |
|---|---|---|---|
| ① 기초 이론 | 전시 학습 확인 (초급 4·중급 3·고급 3문항) | 문항당 2점: 첫 시도 정답 2점, 두 번째 정답 1점, 오답 0점 | 20 |
| ② 기초 실험 준비 | 준비물·보호구·안전 수칙·과정 순서 | 실험 도구 5, 보호구 4, 안전 수칙 OX 7, 과정 순서 4 | 20 |
| ③ 가상 실험 | 직접 조작하고 관찰·분석 | 실험 조작 10, 관찰 기록 10, 입자 모형 12, 반응식 8 | 40 |
| ④ 결과 보고서 | 자동으로 채워진 결과에 고찰 5문항을 작성해 제출 | 문항당 4점. 자동 채점 후 교사가 0~20점으로 확정 | 20 |

## 파일 구성

```
├─ index.html          실험실 페이지 (GitHub Pages 첫 화면)
├─ config.js           Apps Script 주소 설정 (여기만 고치면 됩니다)
├─ .nojekyll           GitHub Pages 설정용 빈 파일
└─ apps-script/
   └─ Code.gs          구글 드라이브 성적관리 코드 (구글 시트에 붙여 넣음)
```

## 구글 드라이브 성적관리 파일

Apps Script를 붙인 구글 시트 하나가 성적관리 파일이 됩니다. 학생이 활동할 때마다 자동으로 채워집니다.

| 시트 | 내용 |
|---|---|
| **성적표** | 반·번호·성명, ①~④ 단계 점수와 세부 점수(도구·보호구·안전OX·순서 / 조작·관찰·입자모형·반응식), 총점, 진행 상태, 제출 시각 |
| **보고서** | 학생별 관찰 기록(0·2·5·10·20분)과 고찰 답안 Q1~Q5, 자동채점·교사확정 점수 |
| **반별 통계** | 반별 참여 인원, 보고서 제출 인원, 단계별 평균, 총점 평균·최고·최저 (자동 계산) |
| 학생기록 | 웹 페이지와 주고받는 원본 데이터 (직접 고치지 마세요) |

- **결과보고서 점수 확정:** 성적표(또는 보고서)의 노란색 **④ 교사확정** 칸에 0~20점을 입력하면 총점과 교사 화면에 바로 반영됩니다. 칸을 비우면 자동채점 점수가 쓰입니다. 교사 화면에서 확정한 점수도 시트에 그대로 들어옵니다.
- 시트 메뉴 **🧪 가상실험실**
  - 처음 설정하기 / 교사 비밀번호 바꾸기
  - 성적표·보고서 반/번호순으로 다시 정리
  - 반별 통계 새로 만들기
  - 선택한 학생 기록 삭제 / 모든 학생 기록 초기화
- 엑셀로 받으려면 **파일 → 다운로드 → Microsoft Excel(.xlsx)** 을 쓰면 됩니다.

## 설치 방법

### 1단계. 구글 드라이브에 성적관리 시트 만들기

1. 구글 드라이브에서 **새로 만들기 → Google 스프레드시트**를 만듭니다. (예: `통합과학실험실_성적관리`)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 💾 저장합니다.
4. 구글 시트 탭으로 돌아와 **새로고침(F5)** 하면 위쪽에 **🧪 가상실험실** 메뉴가 생깁니다.
5. **🧪 가상실험실 → 처음 설정하기**를 누릅니다.
   - 처음 한 번은 권한 승인 창이 뜹니다: 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용
   - 교사 비밀번호를 묻는 창에 비밀번호(예: `0601`)를 입력합니다. 비밀번호는 이 파일에만 저장되고 GitHub에는 올라가지 않습니다.

### 2단계. 웹 앱으로 배포하기

1. Apps Script 화면 오른쪽 위 **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
2. **배포** → 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

### 3단계. GitHub에 주소 넣기

1. GitHub 저장소에서 `config.js` → 연필(✏️) → 따옴표 안에 주소 붙여 넣기 → **Commit changes**
   ```js
   window.LAB_CONFIG = {
     GAS_URL: "https://script.google.com/macros/s/AKfycb.../exec"
   };
   ```
2. **Settings → Pages**에서 Branch: **main / (root)** 가 켜져 있는지 확인합니다.
3. 1~2분 뒤 `https://sj20190405-arch.github.io/shortview-science-lab/` 에 학생이 접속합니다.

> `config.js`를 비워 두면 **미리보기 모드**로 동작합니다. 기록이 각자의 브라우저에만 저장되고 성적관리 시트에는 모이지 않습니다.

## 사용 방법

- **학생:** 접속 → 학생 입장 → 반·번호·성명 입력 → 단계 선택 화면에서 ①~④ 진행 → 결과보고서 제출
- **교사 (웹):** 같은 주소 → 교사 입장 → 비밀번호 → 단계별 현황, 학생별 점수, 보고서 보기, ④ 점수 확정, **📊 구글 시트 성적표 열기**
- **교사 (드라이브):** 성적관리 시트에서 성적표·보고서·반별 통계 확인, ④ 교사확정 칸 입력

## 수정할 때

- **Code.gs를 고친 경우:** Apps Script에서 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**. URL은 그대로 유지됩니다.
- **비밀번호 변경:** 시트 메뉴 **🧪 가상실험실 → 교사 비밀번호 바꾸기** (다시 배포할 필요 없음)
- **반 수(1~13반)나 번호(1~35번)를 바꿀 경우:** `index.html`에서 `i<=13`, `i<=35`를 찾아 고치고, `Code.gs`의 `CLASS_COUNT`도 같이 고칩니다.

## 참고

- 결과보고서는 제출한 뒤에는 수정할 수 없습니다.
- ④단계 자동 채점은 핵심어를 기준으로 매긴 잠정 점수입니다. 교사 화면에서 확인한 뒤 **점수 확정**을 눌러 주세요.
- 산화수는 다루지 않습니다. (수업지도안 유의 사항)
