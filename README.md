# 한슬쌤의 '숏'터뷰 통합과학실험실

동패고등학교 1학년 통합과학 가상실험실입니다.
**통합과학2 Ⅰ-2-01 산화·환원 반응의 규칙성** (교과서 38~43쪽, 3/12차시)의 탐구 활동인 **구리와 질산 은 수용액의 산화·환원 반응 관찰하기**를 4단계로 진행합니다.

- 학생: 반·번호·성명을 입력해야 입장할 수 있습니다. 같은 정보로 다시 들어오면 이어서 진행됩니다.
- 교사: 비밀번호를 입력하면 단계별 진행 현황, 학생별 점수, 최종 결과보고서를 볼 수 있습니다.
- 평가 결과(점수)는 교사 화면에만 표시됩니다.

## 평가 구성 (100점, 세부 점수는 1점 단위)

| 단계 | 활동 | 세부 배점 | 합계 |
|---|---|---|---|
| ① 기초 이론 | 전시 학습 확인 (초급 4·중급 3·고급 3문항) | 문항당 2점: 첫 시도 정답 2점, 두 번째 정답 1점, 오답 0점 | 20 |
| ② 기초 실험 준비 | 준비물·보호구·안전 수칙·과정 순서 | 실험 도구 5, 보호구 4, 안전 수칙 OX 7, 과정 순서 4 | 20 |
| ③ 가상 실험 | 직접 조작하고 관찰·분석 | 실험 조작 10, 관찰 기록 10, 입자 모형 12, 반응식 8 | 40 |
| ④ 결과 보고서 | 자동으로 채워진 결과에 고찰 5문항을 작성해 제출 | 문항당 4점. 자동 채점 후 교사가 0~20점으로 확정 | 20 |

## 파일 구성

```
├─ index.html          실험실 페이지 (GitHub Pages 첫 화면)
├─ config.js           Apps Script 주소 설정 (여기만 고치면 됩니다)
├─ .nojekyll           GitHub Pages 설정용 빈 파일
└─ apps-script/
   └─ Code.gs          구글 시트 저장·교사 인증 서버 코드
```

## 설치 방법

### 1단계. 구글 시트 + Apps Script (학생 기록 저장소)

1. 구글 드라이브에서 새 구글 시트를 만듭니다. (예: `통합과학실험실_기록`)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**
   - 속성: `TEACHER_PW`
   - 값: 교사 비밀번호 (예: `0601`)
   - 비밀번호는 이곳에만 저장되고 GitHub에는 올라가지 않습니다.
5. 오른쪽 위 **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고 권한을 승인합니다. (고급 → 이동 허용)
7. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

### 2단계. GitHub 저장소 + GitHub Pages (학생 접속 주소)

1. GitHub에서 새 저장소를 만듭니다. (예: `shortview-science-lab`, Public)
2. **Add file → Upload files**로 이 폴더의 파일을 모두 올립니다. (`apps-script` 폴더 포함)
3. 저장소에서 `config.js`를 열고 연필(✏️)을 눌러 1단계에서 복사한 주소를 붙여 넣은 뒤 **Commit changes**를 누릅니다.
   ```js
   window.LAB_CONFIG = {
     GAS_URL: "https://script.google.com/macros/s/AKfycb.../exec"
   };
   ```
4. **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → Save
5. 1~2분 뒤 표시되는 주소(`https://아이디.github.io/shortview-science-lab/`)를 학생들에게 안내합니다. QR 코드로 만들어 두면 편리합니다.

> `config.js`를 비워 두면 **미리보기 모드**로 동작합니다. 기록이 각자의 브라우저에만 저장되고, 교사 화면에는 예시 학생이 표시됩니다.

## 사용 방법

- **학생:** 접속 → 학생 입장 → 반·번호·성명 입력 → ①~④ 단계 순서대로 진행 → 결과보고서 제출
- **교사:** 같은 주소 → 교사 입장 → 비밀번호 입력
  - 20초마다 자동 새로고침되는 단계별 현황(완료·진행 중·미시작)
  - 학생별 단계 점수와 총점, 최근 활동 시각
  - **보고서 보기**: 관찰 기록, 고찰 답안, 세부 점수, ④단계 점수 확정
  - 모든 기록은 구글 시트의 `학생기록` 탭에도 한 줄씩 쌓입니다.

## 수정할 때

- **Code.gs를 고친 경우:** Apps Script에서 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이때 URL은 그대로 유지됩니다.
- **비밀번호를 바꿀 경우:** 스크립트 속성의 `TEACHER_PW` 값만 바꾸면 됩니다. 다시 배포할 필요는 없습니다.
- **반 수(1~13반)나 번호(1~35번)를 바꿀 경우:** `index.html`에서 `i<=13`, `i<=35`를 찾아 고칩니다.

## 참고

- 결과보고서는 제출한 뒤에는 수정할 수 없습니다.
- ④단계 자동 채점은 핵심어를 기준으로 매긴 잠정 점수입니다. 교사 화면에서 확인한 뒤 **점수 확정**을 눌러 주세요.
- 산화수는 다루지 않습니다. (수업지도안 유의 사항)
